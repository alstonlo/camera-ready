# Limitations

State each limitation once and precisely, without apology. Flag a decoy limitation that hides the real weakness, and cut a duplicate only when a length request reaches it in the [triage order](../../references/guide.md#triage-order). Explain how each limitation affects the findings ("results may not transfer to larger models, since every run uses the same 100M-parameter backbone"). A limitation phrased as future work must still say what the current results do not cover.
