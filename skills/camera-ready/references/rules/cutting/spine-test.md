# Apply the spine test before cutting sentences

To apply the spine test, state the core claims in one to three sentences and summarize each paragraph's role in one line. Classify each paragraph as **central**, **supporting**, **ancillary**, or **off-spine** (see Details). Treat a paragraph that contains counterevidence or other [protected content](protected-sentences.md) as supporting if it is not central. If no short, specific title summarizes a section, flag its competing points before cutting. When [the request](idea-cuts.md) permits cutting, cut or relocate off-spine paragraphs, shorten ancillary ones, and then edit [sentence by sentence](sentence-dependencies.md). Keep a cut only if the argument remains at least as clear.

## Details

The core claims form the text's spine. A paragraph is **central** if it states a core claim, and **supporting** if readers need it to understand or evaluate one. It is **ancillary** if it is relevant but readers can evaluate the core claims without it, and **off-spine** if it does not relate to them. Never treat a paragraph that contains counterevidence or other protected content as expendable.

Writing a short title for a section tests whether the section develops one coherent point. This check examines what the section says, not the printed heading above it, so a conventional heading such as "Results" is not a defect.

## Examples

**Example 1.** The author asks to shorten a draft on whether gravel reduces soil erosion. The sentence on aquarium decoration does not support any claim in the paper.

> **Bad.** Gravel reduces soil erosion in our tests. Gravel also decorates aquariums.
>
> **Good.** Gravel reduces soil erosion in our tests.

**Example 2.** The author asks to shorten a draft whose core claim is that the mesh keeps leaves out. Blocking grit is an ancillary point that readers do not need to evaluate that claim.

> **Bad.** The mesh prevents leaf entry. A finer mesh might also block grit; grit particles are smaller than leaves.
>
> **Good.** The mesh prevents leaf entry. A finer mesh might also block grit.

**Example 3.** The author asks to shorten a draft that tests whether a mesh excludes debris. An editor proposes cutting the finding that sand passes through the mesh, treating it as off-spine even though it is counterevidence.

> **Bad.** The mesh blocks leaves.
>
> **Good.** The mesh blocks leaves but lets sand through.

**Example 4.** The author asks to shorten a section that covers two unrelated points: leaf blockage and pump power. Because no short, specific title summarizes both points, the editor flags the competing points instead of cutting the pump measurement.

> **Bad.** The mesh blocks leaves.
>
> **Good.** The mesh blocks leaves. The pump draws 5 W.
