# Flag comparisons with prior work that readers cannot yet understand

Detailed comparisons with prior work may appear in any section. Leave each comparison in place, and flag it only if it appears before material that readers need to understand it. Do not flag background that readers need to understand the problem. For what to say in a comparison, follow the [rule on comparing with prior work](prior-work-comparisons.md).

## Details

This rule has no further details.

## Examples

**Example 1.** In this draft, readers can compare fly sizes in the introduction but need the definition in Methods to compare mesh ratios. The editor flags the mesh-ratio comparison and proposes the move below.

> **Bad.** Introduction: Lee's screen blocks adult flies; ours also blocks small flies. Our mesh ratio is lower. Methods: We define the mesh ratio.
>
> **Good.** Introduction: Lee's screen blocks adult flies; ours also blocks small flies. Methods: We define the mesh ratio. Our mesh ratio is lower.
