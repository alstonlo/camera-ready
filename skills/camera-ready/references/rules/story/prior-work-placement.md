# Flag comparisons with prior work that readers cannot yet understand

Flag a comparison with prior work if readers need material from a later section to understand it, and leave it in place. Do not flag background needed to understand the problem. Within a section, follow [explanation order](../prose/explanation-order.md).

## Details

This rule has no further details.

## Examples

**Edit 1.** Suppose readers need the mesh-ratio definition in Methods to understand the mesh-ratio comparison, but can already compare fly sizes. After is a proposal to the author.

> **Before.** Introduction: Lee's screen blocks adult flies; ours also blocks small flies. Our mesh ratio is lower. Methods: We define the mesh ratio.

> **After.** Introduction: Lee's screen blocks adult flies; ours also blocks small flies. Methods: We define the mesh ratio. Our mesh ratio is lower.

The fly-size comparison stays in the introduction because readers can already understand it there.
