# State the gap's cost

Describe both parts of the problem: the condition and its cost to the reader. Readers need both to recognize a problem. The statement "No prior work studies X" gives only a condition. Ask what the reader loses, pays, or cannot do as a result. Flag a missing cost.

## Examples

- Bad: "No prior system supports incremental updates."
- Good: "No prior system supports incremental updates, so every schema change forces a full rebuild."
