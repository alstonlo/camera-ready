# Explain why the evidence supports the claim

When readers outside the subfield may not see why a measurement or reason supports a claim, explain the reasoning that connects them. Check that the assumptions behind that reasoning hold in this study. Use only support from the draft. If the draft omits the connection, flag the gap instead of inventing a reason. Follow [scope](../claims/scope.md) for claims that exceed what the measurement establishes, and [formal support](../claims/evidence-kind.md) for conclusions from a theorem.

## Details

If readers dispute a principle used to connect evidence to a claim, that principle needs support. You need not explain a step that readers already understand and accept. For conclusions about cause and effect, follow [causal language](../claims/causal-language.md).

## Examples

> **Context.** The draft states that the sensor rings a bell only when the tank is full. The Good version proposes an explanation for the author.
>
> **Bad.** The bell rang, so the tank was full.
>
> **Good.** The sensor rings the bell only when the tank is full. The bell rang, so the tank was full.

> **Context.** The draft states that the sample contains only sand and water and that drying removes only water. The Good version proposes an explanation for the author.
>
> **Bad.** Drying reduces the sample's mass by 3 g, so it contained 3 g of water.
>
> **Good.** The sample contains only sand and water, and drying removes only water. Drying reduces the sample's mass by 3 g, so it contained 3 g of water.

> **Context.** The draft states that the green indicator lights only when the lid is sealed, while the time comparison needs no explanation. The Good version proposes an explanation for the author.
>
> **Bad.** Filling takes 4 minutes and draining takes 6 minutes, so draining takes longer. The indicator is green, so the lid is sealed.
>
> **Good.** Filling takes 4 minutes and draining takes 6 minutes, so draining takes longer. The indicator lights only when the lid is sealed. The indicator is green, so the lid is sealed.

> **Context.** The draft notes that readers dispute whether this dye turns red only in acid, and it cites Lee's calibration to support that link. The Good version proposes an explanation for the author.
>
> **Bad.** The dye turns red, so the liquid is acidic.
>
> **Good.** Lee's calibration shows that this dye turns red only in acid. The dye turns red, so the liquid is acidic.
