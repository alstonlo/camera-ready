# Keep the argument linear

Discuss each topic in one place; only the core idea returns in every section. The [rule against alternation](../prose/paragraphs.md) also applies across sections: do not return to a topic after discussing another (A, B, A). Flag it if the repair would reorder sections.

Order the argument by its logic rather than by the sequence of the work. Do not give a part more space because it took more time. Under the [triage order](../cutting/triage-order.md), an approach the text rejects belongs in the main text only as a negative result. State its flaw before describing it so the reader knows from the outset why it was rejected.

Describe each part of the method in detail proportional to its importance to the core claims defined by the spine test. Describing every component at equal depth obscures which one makes the contribution.
