# Give one headline number per claim

Choose the number the reader should remember and put the others in the table. Describe the pattern in words: whether the effect is consistent, where it grows, and where it fails. Use the table to establish that pattern, and follow this order for [quantified comparisons](../prose/quantified-comparatives.md).

Use running text to state the conclusion and refer to the table. Remove numbers already in the table, retaining the headline number under the [rule on uncertainty](../claims/uncertainty.md) and the [rule on statistical conclusions](../claims/significance.md).
