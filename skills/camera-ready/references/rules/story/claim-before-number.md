# State the claim before the number

State the finding in words before its supporting number, and refer to the table for the remaining values. Check which claim each number supports. Flag any number without an identifiable claim. Move it only if the request allows relocation and a suitable place exists. When a table gives a number, remove it from the text only under the [headline-number rule](headline-number.md), keeping needed comparisons and uncertainty.

## Details

This rule has no further details.

## Examples

**Edit 1.** The edit moves "the new brakes shorten stopping distance" to a separate opening sentence and removes "showing that", so that readers encounter the finding before the supporting decrease from 18 to 12 meters.

> **Before.** The average stopping distance falls from 18 m to 12 m, showing that the new brakes shorten stopping distance.
>
> **After.** The new brakes shorten stopping distance. The average stopping distance falls from 18 m to 12 m.
