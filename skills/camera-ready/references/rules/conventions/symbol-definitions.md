# Define each symbol by its first use and give it one meaning

Define every symbol, at least informally, at or before its first use, and [refresh the definition after a gap](shorthand-reminders.md). Give each symbol one meaning and each object one symbol. Flag conflicting meanings, unused definitions, easily confused names, or dense notation; do not rename symbols yourself. Distinguish a function from its value: if $V$ is a potential, flag "$V = 0.31$" when "$V(x_0) = 0.31$" is meant. Keep local definitions near where they are used. When global definitions are scattered, move them into an existing notation section only if the request [allows relocation](../cutting/idea-cuts.md); otherwise flag them, and never create a new notation section. For unnecessary indices, repeated expressions, and verbal alternatives, see the page.

## Details

Check later equations, captions, figures, and appendices before flagging a symbol definition as unused.

Propose notation improvements to the author rather than rewriting equations yourself: suggest words when an index adds no distinction, a short name for a repeated complex expression, or collection notation, such as a vector or set, when it reveals structure.

## Examples

> **Bad.** We compare $h$ across plants. The symbol $h$ denotes plant height.
>
> **Good.** The symbol $h$ denotes plant height. We compare $h$ across plants.

The draft defines $V$ as a potential function and states that 0.4 is its value at $x_0$; the Good line proposes a notation repair to the author.

> **Bad.** The potential is $V=0.4$.
>
> **Good.** The potential is $V(x_0)=0.4$.

The draft defines both quantities and uses $w$ for moisture content in its tables; the Good line proposes reconciling the symbols for the author.

> **Bad.** Let $m$ denote mass and $m$ denote moisture content.
>
> **Good.** Let $m$ denote mass and $w$ denote moisture content.

The draft uses both $h$ and $z$ for the same height; the Good line proposes removing the duplicate symbol for the author.

> **Bad.** Let $h$ denote height. We report the height $z$.
>
> **Good.** Let $h$ denote height. We report the height $h$.

The document's font renders lowercase $l$ and uppercase $I$ alike, and the table already uses $L$ for length; the Good line proposes replacing $l$ with $L$ for the author.

> **Bad.** Let $l$ denote length and $I$ denote current.
>
> **Good.** Let $L$ denote length and $I$ denote current.

The draft uses $h$ for height but never uses $w$ in the text, captions, figures, or appendices; the Good line proposes removing the unused definition for the author.

> **Bad.** Let $h$ denote height and $w$ denote width. We report $h$.
>
> **Good.** Let $h$ denote height. We report $h$.

The symbol $h$ is used only in the final sentence.

> **Bad.** Let $h$ denote height. We prepare the soil and label the pots. We measure $h$.
>
> **Good.** We prepare the soil and label the pots. Let $h$ denote height. We measure $h$.

The draft uses both symbols throughout the paper and already has a Notation section; because relocation is not authorized, the Good line proposes moving the definition of $w$ for the author.

> **Bad.** Notation: Let $h$ denote height. Methods: Let $w$ denote width.
>
> **Good.** Notation: Let $h$ denote height. Let $w$ denote width. Methods:

The draft defines $T_1$ as its only temperature and never uses the subscript to distinguish readings; the Good line proposes using the word "temperature" for the author.

> **Bad.** We record $T_1$.
>
> **Good.** We record the temperature.

The draft defines $a$, $b$, $c$, and $d$ and repeats this ratio; the Good line proposes naming the ratio $R$ for the author.

> **Bad.** We compare $(a+b)/(c+d)$ across sites and plot $(a+b)/(c+d)$ over time.
>
> **Good.** Let $R=(a+b)/(c+d)$. We compare $R$ across sites and plot $R$ over time.

The draft treats the three coordinates as a single position vector; the Good line proposes vector notation for the author.

> **Bad.** We report $(x_1,x_2,x_3)$ and compare $(x_1,x_2,x_3)$ across trials.
>
> **Good.** Let $\mathbf{x}=(x_1,x_2,x_3)$. We report $\mathbf{x}$ and compare $\mathbf{x}$ across trials.
