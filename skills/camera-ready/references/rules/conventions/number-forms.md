# Spell out small counts and use numerals for measurements

In prose, spell out a small count before a noun ("two passes"). Use numerals for measurements, quantities with units, mathematical values, numbered names ("Experiment 4"), and parameter settings ("3 cycles"). Follow the venue cutoff if one exists, otherwise the draft's consistent cutoff. Match forms when comparing quantities ("1.5M and 0.2M"); flag any edit that requires rounding or unit conversion.

## Details

For percentages and differences in percentage points, follow the rule on [variability](../claims/variability.md).

## Examples

**Example 1.**

> **Bad.** The tray holds 4 jars, each containing 200 mL of water.
>
> **Good.** The tray holds four jars, each containing 200 mL of water.

**Example 2.** The draft spells out counts below ten. Its protocol specifies "3 cycles" as a parameter setting.

> **Bad.** We use 2 trays and run 3 cycles.
>
> **Good.** We use two trays and run 3 cycles.

**Example 3.**

> **Bad.** The counts are 2.4M and 800,000.
>
> **Good.** The counts are 2.4M and 0.8M.

**Example 4.** The draft reports both counts and rounds 812,345 to 0.8M elsewhere. The editor flags the rounding for the author rather than rounding the count directly.

> **Bad.** The counts are 2.4M and 812,345.
>
> **Good.** The counts are 2.4M and 0.8M.
