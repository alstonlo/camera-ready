# Set off non-restrictive clauses with commas

Put commas around a non-restrictive clause, which adds information without restricting the noun. Do not add commas to a restrictive clause just because it starts with "which". Change restrictive "which" to "that" only when the venue requires it. Do not place commas around a symbol naming the preceding noun ("a directed graph G with source s").

## Details

This rule has no further details.

## Examples

**Edit 1.** Every seedling is in the greenhouse.

> **Before.** The seedlings which are in the greenhouse need water.
>
> **After.** The seedlings, which are in the greenhouse, need water.

**Edit 2.** The venue permits restrictive "which", and only seedlings with red tags need water.

> **Before.** The seedlings, which have red tags, need water.
>
> **After.** The seedlings which have red tags need water.

**Edit 3.**

> **Before.** A circle, $C$, encloses the triangle.
>
> **After.** A circle $C$ encloses the triangle.
