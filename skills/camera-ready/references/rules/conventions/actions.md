# State performed actions directly

When the draft says an action was performed, replace "can", "aims to", or "seeks to" with the direct action. Keep the wording for a capability the work did not use and for a goal the draft says remains unattained: removing that distinction would [change the claim](../claims/overclaiming.md).

## Details

Distinguish a description of the procedure actually used from a description of what the implementation permits. A capability can remain unused in the reported experiment. Likewise, a stated research goal does not establish that the work achieved it. Edit the wording only when the draft identifies the action as part of the procedure performed.

## Examples

The draft states that weighing each seed is part of the procedure performed.

- Bad: We can weigh each seed before planting.
- Good: We weigh each seed before planting.
