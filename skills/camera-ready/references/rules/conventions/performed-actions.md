# State performed actions directly

When the draft shows an action was performed, replace "can", "aims to", or "seeks to" with a direct verb. Keep these words for a capability the study did not use and a goal the authors have not reached; removing them would [change the claim](../claims/unsupported-labels.md).

## Details

This rule has no further details.

## Examples

> **Context.** The draft establishes that the authors weigh each seed before planting.
>
> **Bad.** We can weigh each seed before planting.
>
> **Good.** We weigh each seed before planting.

> **Context.** The draft establishes that the authors measure every leaf.
>
> **Bad.** We aim to measure each leaf.
>
> **Good.** We measure each leaf.

> **Context.** The draft establishes that the authors remove loose soil.
>
> **Bad.** We seek to remove loose soil.
>
> **Good.** We remove loose soil.

> **Context.** The draft states that the authors weigh each seed separately and never weigh a whole plant.
>
> **Bad.** The scale can weigh whole plants. We can weigh each seed separately.
>
> **Good.** The scale can weigh whole plants. We weigh each seed separately.

> **Context.** The draft states that the authors sort these seeds by hand, whereas automated sorting remains an unreached goal.
>
> **Bad.** We aim to automate sorting. We can sort these seeds by hand.
>
> **Good.** We aim to automate sorting. We sort these seeds by hand.
