# State performed actions directly

When the draft shows that an action was performed, replace "can", "aims to", or "seeks to" with a direct verb. Keep those words for a capability that the study did not use and for a goal that the draft says remains unattained; removing that distinction would [change the claim](../claims/unsupported-labels.md).

## Details

This rule needs no details beyond its summary.

## Examples

The draft states that the authors weigh each seed before planting.

> Bad: We can weigh each seed before planting.
>
> Good: We weigh each seed before planting.

The draft states that the authors measure every leaf.

> Bad: We aim to measure each leaf.
>
> Good: We measure each leaf.

The draft states that the authors remove loose soil.

> Bad: We seek to remove loose soil.
>
> Good: We remove loose soil.

The draft states that the authors weigh each seed separately and never weigh a whole plant.

> Bad: The scale can weigh whole plants. We can weigh each seed separately.
>
> Good: The scale can weigh whole plants. We weigh each seed separately.

The draft states that the authors sort these seeds by hand and that automated sorting remains an unattained goal.

> Bad: We aim to automate sorting. We can sort these seeds by hand.
>
> Good: We aim to automate sorting. We sort these seeds by hand.
