# Make theorem statements self-contained

Make the sentence before a theorem, lemma, or algorithm complete or end it with a colon. Make the statement self-contained by naming its objects ("The function H defined in (5) is continuous"), and exclude motivation and commentary. Within a theorem statement, define each symbol before using it. If the hypotheses exceed a few lines, flag the statement and suggest named conditions defined before the theorem ("Assumption 1 (smoothness)").
