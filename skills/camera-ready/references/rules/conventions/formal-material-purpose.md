# Explain why an equation or definition is needed

Flag any central equation or definition whose purpose the draft never states; do not infer one. If the explanation appears later in the same paragraph or section, move it before the equation or definition. If it appears only in another section, flag the proposed move. Follow [formal support](../claims/evidence-kind.md) when an application depends on unstated conditions.

## Details

This rule has no further details.

## Examples

**Edit 1.** Before:

> We use $v=d/t$. This equation converts each runner's distance and elapsed time into average speed.

After:

> To convert each runner's distance and elapsed time into average speed, we use $v=d/t$.

**Edit 2.** Suppose the draft explains in another section that the equation converts each runner's distance and elapsed time into average speed. The change below is a proposal to the author. Before:

> We use $v=d/t$.

After:

> To convert each runner's distance and elapsed time into average speed, we use $v=d/t$.
