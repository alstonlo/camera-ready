# Avoid using one technical term as both a noun and a verb

If using a technical term as both noun and verb in one sentence forces rereading ("we sample 1,000 samples"), replace the verb with an ordinary one ("we draw 1,000 samples") or split the sentence. Otherwise, leave it alone.

## Details

When replacing a verb, keep [technical names](term-consistency.md) unchanged.

## Examples

**Edit 1.**

> **Before.** We model growth. The model fits the observations. We test the test's accuracy.

> **After.** We model growth. The model fits the observations. We assess the test's accuracy.

The uses of "model" in separate sentences are clear and need no revision.
