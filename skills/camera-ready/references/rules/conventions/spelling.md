# Spell each word the same way throughout

Use US or UK spelling consistently. For terms with two accepted forms, such as "dataset" and "data set", follow venue requirements; if the venue specifies neither form, use the draft's more frequent variant.

## Details

This rule has no further details.

## Examples

**Edit 1.** Suppose the rest of the draft uses "dataset" and the venue has no preference between the two forms.

> **Before.** The data set contains labeled traffic flows.

> **After.** The dataset contains labeled traffic flows.

**Edit 2.** Imagine the venue requires "data set", although "dataset" is more frequent in the draft.

> **Before.** The dataset contains hourly readings.

> **After.** The data set contains hourly readings.
