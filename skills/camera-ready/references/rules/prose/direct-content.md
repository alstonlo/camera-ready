# State the content directly

When a sentence only promises later content or calls a topic complex, replace it with the draft's content, or flag the gap. Delete trailing promises such as "and we discuss each below" when the content is already present. Keep a summary of the main idea and any count whose items follow immediately ("We make four observations. First, ..."). Keep statements of real uncertainty, a real dispute, an unresolved definition, or a [limitation](../claims/limitations.md). To test a sentence, cover the rest of the paragraph and ask whether the sentence alone says anything readers can understand or check.

## Details

This rule has no further details.

## Examples

**Edit 1.** The draft identifies both sources elsewhere. The edit replaces the promise to discuss two sources later with "Water is lost through leaks and evaporation", so readers learn the sources directly.

> **Before.** Two sources of water loss are discussed later.
>
> **After.** Water is lost through leaks and evaporation.

**Edit 2.** The edit deletes "which we discuss below" as an unnecessary promise and keeps "We make two observations" because both observations follow immediately.

> **Before.** We make two observations, which we discuss below. First, the lid bends. Second, the seal leaks.
>
> **After.** We make two observations. First, the lid bends. Second, the seal leaks.

**Edit 3.** The edit deletes "This issue is complex" because it gives no specific information, and keeps the unresolved definition of partial failure because it explains what the tests cannot establish.

> **Before.** This issue is complex. We have not defined partial failure, so these tests cannot distinguish it from complete failure.
>
> **After.** We have not defined partial failure, so these tests cannot distinguish it from complete failure.

**Edit 4.** The draft promises an explanation but never provides one; Before is an editor's proposed addition. The edit removes the unsupported latch explanation, restores the draft's promise, and adds a flag identifying the missing explanation, so the author can fill the gap without the editor inventing a cause.

> **Before.** The lid stays shut because its latch resists pressure.
>
> **After.** We explain below why the lid stays shut. Flag for the author: The promised explanation is missing.
