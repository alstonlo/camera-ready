# Name the measured quantity instead of an umbrella noun

Replace umbrella nouns such as "performance" or "quality" with the measured quantity. Keep a defined collective label when the statement applies to all quantities it covers.

## Details

This rule has no further details.

## Examples

**Edit 1.** Suppose the draft identifies purity as the quantity measured by the 98% value.

> **Before.** We assess quality using purity and yield. Performance reaches 98%.

> **After.** We assess quality using purity and yield. Purity reaches 98%.

"Quality" stays because it names purity and yield together.
