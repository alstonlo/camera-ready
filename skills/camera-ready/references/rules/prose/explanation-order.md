# Explain ideas in the order readers need

State the main idea before explaining how it works. State a finding and its interpretation before supporting evidence. Put a section's claim in its first paragraph, and open each paragraph as the [paragraph rule](paragraph-development.md) directs. Define unfamiliar terms before using them. If readers need a later explanation to understand an earlier sentence, move that explanation earlier. You may reorder sentences within a paragraph and paragraphs within a section, but flag moves between sections. Within a sentence, follow [old before new](old-before-new.md) and [stress position](stress-position.md).

## Details

To test the order, cover everything after a sentence and check whether readers have what they need to understand the visible text. A later sentence that only adds precision does not need to move. After moving an explanation earlier, check that every term it uses is already defined at its new position.

## Examples

**Edit 1.** The draft has not defined settling time before this passage. The edit moves the definition before the measurement sentence, so that readers know what settling time means when they read what was measured.

> **Before.** We measured the settling time for each mixture. Settling time is the time needed for solid particles in a liquid to sink to the bottom.
>
> **After.** Settling time is the time needed for solid particles in a liquid to sink to the bottom. We measured the settling time for each mixture.

**Edit 2.** The edit moves "Only wet boards sagged, suggesting that moisture weakens them" before the counts, so that readers encounter the finding and its interpretation before the supporting evidence.

> **Before.** All six wet boards sagged; none of the dry boards did. Only wet boards sagged, suggesting that moisture weakens them.
>
> **After.** Only wet boards sagged, suggesting that moisture weakens them. All six wet boards sagged; none of the dry boards did.
