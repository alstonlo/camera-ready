# Describe the work without narrating manuscript revisions

In the paper, replace revision accounts (diff-anchored prose), such as "In this revised version, we clarify" or "As suggested by the reviewer", with the resulting scientific content. Preserve the explanation, evidence, and justification, including material added during review. Revision history belongs in the response letter or change log. Keep a substantive comparison between versions of a method when that comparison is itself part of the study.

## Details

Remove the editorial framing around a scientific statement, not the statement itself. Readers need the argument for correctness even when a reviewer prompted the authors to add it.

A comparison between software or algorithm versions can be the study's subject. Preserve that comparison; it is not an account of changes made to the manuscript.

## Examples

- Bad: As requested by the reviewer, we add that each jar contains 200 mL of water.
- Good: Each jar contains 200 mL of water.
