# Delete transition chains that announce more text

Typical chains repeat openings such as "Moreover", "Furthermore", and "Additionally". Keep transitions that show a [valid logical relation](../prose/transitions.md). Do not replace additive sentences with unsupported causal, temporal, or contrastive connections.

## Details

This rule has no further details.

## Examples

**Edit 1.** Imagine these sentences open consecutive paragraphs about independent setup choices.

> **Before.** Moreover, all participants use the same tablet. Additionally, each session lasts 20 minutes.

> **After.** All participants use the same tablet. Each session lasts 20 minutes.

**Edit 2.**

> **Before.** Moreover, the tray is steel. Furthermore, its coating is inert. Both properties are required by the protocol.

> **After.** The tray is steel. Furthermore, its coating is inert. Both properties are required by the protocol.

Here "Furthermore" connects two requirements that must both be met, so it does more than announce another sentence.
