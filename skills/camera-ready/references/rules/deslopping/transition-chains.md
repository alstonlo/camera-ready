# Delete transition chains that announce more text

Delete repeated openings such as "Moreover", "Furthermore", and "Additionally" that merely announce more text. Keep transitions that show a [valid logical relation](../prose/transitions.md). Do not replace additive sentences with unsupported causal, temporal, or contrastive connections.

## Details

This rule has no further details.

## Examples

**Edit 1.** These sentences open consecutive paragraphs about independent setup choices. The edit deletes "Moreover" and "Additionally", so that the openings state the choices directly without merely announcing more text or inventing a relation between them.

> **Before.** Moreover, all participants use the same tablet. Additionally, each session lasts 20 minutes.
>
> **After.** All participants use the same tablet. Each session lasts 20 minutes.

**Edit 2.** The edit deletes "Moreover" because it merely announces the next item in the setup. It keeps "Furthermore" because it joins two requirements that must both be met.

> **Before.** Moreover, the tray is steel. Furthermore, its coating is inert. Both properties are required by the protocol.
>
> **After.** The tray is steel. Furthermore, its coating is inert. Both properties are required by the protocol.
